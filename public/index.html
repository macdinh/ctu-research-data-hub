Lộ trình Triển khai Thử nghiệm Miễn phí 100% (Cloud Pilot Setup)

Tối ưu hóa cho giai đoạn thử nghiệm (100 – 1.000 sinh viên) với chi phí 0đ bằng kiến trúc Lưu trữ Lai (Hybrid Cloud Storage).

Sẵn sàng Deploy (Render / Vercel + Supabase + R2)
1. Web Host Miễn phí (Render / Vercel)
render.yaml & vercel.json

Đã tạo sẵn file cấu hình tự động. Bạn chỉ cần đẩy thư mục này lên GitHub và bấm New Web Service trên Render.com hoặc Vercel để nhận ngay tên miền https://... miễn phí.

2. CSDL PostgreSQL (Supabase Free)
supabase/schema.sql

Lưu tài khoản sinh viên, điểm Credits, trích dẫn DOI và dữ liệu Preview JSON (20 dòng đầu). Gói miễn phí 500MB lưu được tới 50.000+ bộ dữ liệu.

3. Lưu trữ Lai Không Giới Hạn
Cloudflare R2 + Google Drive EDU

File nhỏ (< 20MB) lưu trên Cloudflare R2 (10GB Free). Bộ dữ liệu lớn (> 50MB như ảnh AI, GIS) kết hợp link Google Drive trường / Zenodo (50GB Free).
